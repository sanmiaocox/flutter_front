##### 整体一级导航设计
###### 底部导航四部分下的主页设计

根据你的决定（底部导航：**主页**、**已参加观影团的活动**、**消息**、**个人中心**），我们需要将电影发现、观影团浏览、榜单、同城活动等全部整合到主页中。这样主页将成为一个**综合性内容聚合页**，既要内容丰富，又要层次清晰。下面为你设计一套可行且美观的主页方案，并说明如何与观影团特色深度融合。

---

##### 主页整体布局（从上到下）

使用 **CustomScrollView + Sliver** 实现流畅的滚动体验，各模块按重要性排列：

###### 1. 顶部导航栏

- 左侧：应用名称或 Logo。
- 右侧：搜索图标（点击进入全局搜索页，可搜索电影、用户、活动） + 消息图标（如果底部已有“消息”标签，此处可省略，但保留搜索是必要的）。

###### 2. 轮播图（Banner）

- **内容**：展示运营推荐内容，如热门电影、即将上映大片、平台精选观影团活动等。
- **数据来源**：后端配置的广告位（可简单写死几条数据用于演示）。
- **交互**：点击轮播图进入对应的电影详情页或活动详情页。
- **观影团融合**：可放置一个“热门观影团推荐”的横幅，点击进入活动详情。

###### 3. 快捷功能入口（2×4 网格或水平滚动图标）

- **功能**：提供快速导航到核心分类，例如：
    - 正在热映
    - 即将上映
    - 高分经典
    - 同城活动
    - 热门榜单
    - 我的片单（点击进入个人中心的片单管理）
    - 发布动态（可选，但底部已有个人中心，可放在这里）
- **设计**：每个入口为图标+文字，点击跳转到对应列表页（如“正在热映”跳转到电影列表页，带类型筛选）。
- **观影团融合**：“同城活动”直接跳转到观影团列表页（默认按同城筛选）；“热门榜单”可包含“热门观影团榜单”入口。

###### 4. 热门观影团（水平滚动卡片）

- **标题**：左侧“热门观影团”，右侧“更多”按钮（点击进入全部观影团列表页）。
- **卡片设计**：每个卡片显示：
    - 电影海报（作为背景或左侧）
    - 活动标题（如“《奥本海默》IMAX专场”）
    - 活动时间（如“3月25日 19:00”）
    - 地点/线上标识
    - 当前报名人数/上限
    - 发起人头像（小图标）
- **数据来源**：后端按热度（报名人数+讨论数）排序的近期活动。
- **交互**：点击卡片进入活动详情页。
- **观影团特色**：这是直接展示观影团的模块，让用户一进入主页就能发现活动。

###### 5. 热门电影榜单（水平滚动卡片）

- **标题**：左侧“热门电影榜”，右侧“更多”按钮（点击进入完整榜单页）。
- **卡片设计**：电影海报 + 电影名称 + 评分（如有），可显示榜单排名（如No.1）。
- **数据来源**：按评分、热度或标记人数排序的电影列表。
- **交互**：点击进入电影详情页。

###### 6. 热门同城活动（水平滚动卡片或小列表）

- **标题**：左侧“同城观影团”，右侧“更多”按钮（点击进入同城活动列表页）。
- **卡片设计**：与热门观影团类似，但增加距离信息（如“距你2.3km”）。如果做线上模式，可以显示“线上活动”。
- **数据来源**：根据用户IP或默认城市筛选的线下活动（若无地理位置，可展示最近创建的活动，加“同城”标签）。
- **交互**：点击进入活动详情页。
- **观影团融合**：这是观影团的细分场景，突出本地化社交。

###### 7. 热门动态（垂直列表）

- **标题**：左侧“热门讨论”，右侧“更多”按钮（点击进入全部动态列表页）。
- **卡片设计**：与之前设计的动态卡片一致（用户头像、昵称、时间、内容、图片、互动按钮）。
- **数据来源**：按点赞+评论数排序的动态。
- **交互**：点击进入动态详情页（评论页）。

### 其他底部导航页面简要设计

### 1. 已参加观影团的活动

- **页面内容**：分两个Tab——“我发起的”和“我参与的”。
- **列表项**：与观影团卡片类似，但增加状态标签（进行中、已结束、已取消）。
- **交互**：点击进入活动详情页；发起人可进行管理（编辑、取消）。

### 2. 消息

- **页面内容**：通知列表，按时间倒序。
- **通知类型**：点赞、评论、关注、系统通知（活动提醒、报名结果等）。
- **交互**：点击通知跳转到相关内容（动态、活动、个人主页）。

### 3. 个人中心

- **顶部**：用户信息卡片（头像、昵称、简介、关注/粉丝数）。
- **功能列表**：
    - 我的动态
    - 我的影评
    - **我的片单**（个人收藏的电影列表，可创建多个片单，如“想看”、“已看”、“经典收藏”）
    - 我的观影团（入口，点击进入“已参加观影团的活动”页面）
    - 设置
    - 夜间模式切换（可选）
- **交互**：点击各项进入相应页面。

### 如何实现功能分级（融入观影团）

根据之前的功能分级，我们检查核心功能是否都覆盖了：

| 核心功能 | 在主页或其他页面的体现 |
| --- | --- |
| 用户系统 | 登录/注册在进入时处理；个人中心已包含 |
| 电影基础数据 | 主页热门电影、榜单点击进入详情；搜索可查找电影 |
| 观影团核心功能 | 主页热门观影团、同城活动模块；底部“已参加”页面管理个人活动 |
| 社区动态基础 | 主页热门动态模块 |
| 通知系统 | 底部“消息”页面 |

扩展功能（如评分、标记、活动讨论区增强、统计等）可以在二级页面实现，不影响主页简洁性。

### 开发建议

1. **模块化开发**：将主页的每个模块封装成独立的Widget（如`BannerWidget`、`CategoryGridWidget`、`HotPartyWidget`、`MovieRankWidget`等），便于维护和复用。
2. **数据加载**：主页需要多个接口聚合数据，可以后端提供一个聚合接口返回所有模块数据，或者前端并行请求多个接口（使用`Future.wait`）。毕设阶段建议后端提供聚合接口，减少前端多次请求。
3. **缓存策略**：对首页数据可做本地缓存，提升启动速度。
4. **搜索功能**：搜索页可复用电影列表页的网格布局，支持关键字搜索电影、用户、活动。
5. **个人片单**：如果需要实现，可设计为：用户创建片单（如“想看清单”），从电影详情页添加电影。片单列表页可展示所有片单，点击进入片单详情（电影列表）。
