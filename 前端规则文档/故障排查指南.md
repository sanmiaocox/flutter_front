# 前端注册/登录故障排查指南

## 🔍 常见错误分析

### 错误1：Connection refused（连接被拒绝）

#### 错误日志示例
```
ClientException with SocketException: Connection refused (OS Error: Connection refused, errno = 111), 
address = localhost, port = 49562, uri=http://localhost:7070/api/auth/register
```

#### 原因分析
1. **Android模拟器问题**：在Android模拟器中，`localhost` 指向模拟器本身，而不是你的电脑
2. **后端服务未启动**：Spring Boot后端服务没有运行
3. **端口错误**：后端服务不是运行在7070端口

#### 解决方案

##### 方案1：修改API地址（Android模拟器）

**已自动修复**：代码已更新，会自动检测平台并使用正确的地址

- Android模拟器：自动使用 `http://10.0.2.2:7070`
- iOS模拟器：自动使用 `http://localhost:7070`
- 真机：需要使用电脑的局域网IP

##### 方案2：使用电脑局域网IP（推荐用于真机测试）

1. 查看电脑的局域网IP：
   - Windows: 打开CMD，输入 `ipconfig`，查看 IPv4 地址
   - Mac/Linux: 打开终端，输入 `ifconfig`，查看 inet 地址

2. 修改配置文件 `lib/config/api_config.dart`：
```dart
static String get devBaseUrl {
  // 替换为你的电脑IP
  return 'http://192.168.1.100:7070';  // 示例IP
}
```

3. 确保手机和电脑在同一个WiFi网络

##### 方案3：确认后端服务已启动

1. 在后端项目目录执行：
```bash
mvn spring-boot:run
```

2. 看到以下日志说明启动成功：
```
Tomcat started on port(s): 7070 (http)
Started CommunityApplication in X.XXX seconds
```

3. 在浏览器访问测试：
```
http://localhost:7070/hello
```
应该看到：`后端项目启动成功！你好，电影社区！`

### 错误2：Request method 'GET' is not supported

#### 错误日志示例
```json
{
  "code": 500,
  "message": "服务器内部错误：Request method 'GET' is not supported",
  "data": null
}
```

#### 原因分析
1. 后端接收到了GET请求，但接口要求POST请求
2. 可能是浏览器重定向或缓存导致

#### 解决方案

这个错误通常不会在正常的Flutter应用中出现，因为代码中明确使用了POST方法。

如果出现此错误，检查：
1. 确认 `api_service.dart` 中使用的是 `http.post()` 而不是 `http.get()`
2. 清除应用缓存重新安装

### 错误3：参数校验失败

#### 错误日志示例
```json
{
  "code": 400,
  "message": "参数校验失败",
  "data": null
}
```

#### 原因分析
输入的数据不符合后端要求：
- 用户名：2-50个字符
- 手机号：11位数字，以1开头
- 密码：6-20个字符

#### 解决方案
确保输入符合要求，前端已添加验证，但仍需注意：
- 用户名不能为空或太短
- 手机号必须是11位
- 密码至少6位

---

### 错误4：用户名已存在 / 手机号已注册

#### 错误日志示例
```json
{
  "code": 1001,
  "message": "用户名已存在",
  "data": null
}
```
或
```json
{
  "code": 1002,
  "message": "手机号已被注册",
  "data": null
}
```

#### 原因分析
数据库中已有相同的用户名或手机号

#### 解决方案

##### 方案1：更换用户名或手机号
使用不同的用户名或手机号重新注册

##### 方案2：删除测试数据
在Navicat中执行：
```sql
-- 查看所有用户
SELECT * FROM users;

-- 删除指定用户
DELETE FROM users WHERE phone = '12233334444';

-- 或删除所有测试数据
TRUNCATE TABLE users;
```

---

### 错误5：手机号或密码错误

#### 错误日志示例
```json
{
  "code": 1003,
  "message": "手机号或密码错误",
  "data": null
}
```

#### 原因分析
1. 手机号不存在（未注册）
2. 密码输入错误

#### 解决方案
1. 确认手机号已注册
2. 确认密码输入正确
3. 如果忘记密码，在数据库中删除该用户重新注册

## 🛠️ 调试步骤

### 步骤1：检查后端服务

1. 确认后端服务已启动
2. 在浏览器访问：`http://localhost:7070/hello`
3. 应该看到欢迎信息

### 步骤2：检查网络连接

#### 使用Postman测试

1. 打开Postman
2. 创建POST请求：`http://localhost:7070/api/auth/register`
3. 设置Headers：
   - Content-Type: application/json
4. 设置Body（raw JSON）：
```json
{
  "username": "测试用户",
  "phone": "13800138000",
  "password": "123456"
}
```
5. 点击Send
6. 如果成功，说明后端正常，问题在前端配置

### 步骤3：检查前端配置

1. 打开 `lib/config/api_config.dart`
2. 确认地址配置正确：
   - Android模拟器：`http://10.0.2.2:7070`
   - iOS模拟器：`http://localhost:7070`
   - 真机：`http://你的电脑IP:7070`

### 步骤4：查看Flutter日志

运行应用时查看控制台日志：
```
I/flutter: 注册请求: http://10.0.2.2:7070/api/auth/register
I/flutter: 请求体: username=测试用户, phone=13800138000
I/flutter: 注册响应状态码: 200
I/flutter: 注册响应内容: {"code":200,"message":"注册成功",...}
```

如果看到 `Connection refused`，说明网络配置有问题

### 步骤5：测试完整流程

1. 先测试注册
2. 再测试登录
3. 检查Token是否保存
4. 检查是否能跳转到主页

## 📱 不同平台的配置

### Android模拟器

**地址**：`http://10.0.2.2:7070`

**说明**：
- `10.0.2.2` 是Android模拟器访问宿主机的特殊IP
- 代码已自动处理，无需手动修改

**验证**：
在Android模拟器的浏览器中访问：`http://10.0.2.2:7070/hello`

---

### iOS模拟器

**地址**：`http://localhost:7070`

**说明**：
- iOS模拟器可以直接使用localhost
- 代码已自动处理

**验证**：
在iOS模拟器的Safari中访问：`http://localhost:7070/hello`

---

### Android真机

**地址**：`http://你的电脑IP:7070`

**步骤**：

1. 查看电脑IP（Windows）：
```cmd
ipconfig
```
找到 `IPv4 地址`，例如：`192.168.1.100`

2. 修改 `lib/config/api_config.dart`：
```dart
static String get devBaseUrl {
  if (Platform.isAndroid) {
    return 'http://192.168.1.100:7070';  // 替换为你的IP
  }
  // ...
}
```

3. 确保手机和电脑在同一WiFi

4. 确保防火墙允许7070端口

---

### iOS真机

**地址**：`http://你的电脑IP:7070`

**步骤**：同Android真机
