# 收藏夹封面图片功能实现

> **实现日期**: 2026-03-04  
> **版本**: v1.0

---

## 📋 功能概述

为创建收藏夹页面添加封面图片上传功能，用户可以：
1. 从相册选择图片作为封面
2. 输入图片URL作为封面
3. 预览选择的图片
4. 移除已选择的图片

---

## 🎨 UI设计

### 封面图片选择区域

#### 未选择图片时
- 显示虚线边框的占位区域（150px高）
- 中央显示图片图标和提示文字
- 点击可打开相册选择图片
- 建议尺寸提示：16:9

#### 已选择图片时
- 显示图片预览（200px高）
- 右上角显示关闭按钮，可移除图片
- 图片以 cover 方式填充容器

### URL输入框
- 位于图片选择区域下方
- 带有链接图标的前缀
- 支持输入 http:// 或 https:// 开头的URL
- 表单验证确保URL格式正确

## 💻 技术实现

### 1. 依赖包
使用 `image_picker` 包（已安装）：
```yaml
dependencies:
  image_picker: ^1.0.7
```

### 2. 状态管理
```dart
File? _selectedImage;                    // 选择的本地图片
final ImagePicker _picker = ImagePicker();
final _coverImageController = TextEditingController();  // URL输入框
```

### 3. 选择图片
```dart
Future<void> _pickImage() async {
  try {
    final XFile? image = await _picker.pickImage(
      source: ImageSource.gallery,
      maxWidth: 1920,
      maxHeight: 1080,
      imageQuality: 85,
    );

    if (image != null) {
      setState(() {
        _selectedImage = File(image.path);
      });
    }
  } catch (e) {
    // 错误处理
  }
}
```

### 4. 移除图片
```dart
void _removeImage() {
  setState(() {
    _selectedImage = null;
    _coverImageController.clear();
  });
}
```

### 5. 创建收藏夹时传递封面URL
```dart
String? coverImageUrl;
if (_coverImageController.text.trim().isNotEmpty) {
  coverImageUrl = _coverImageController.text.trim();
}

final response = await ApiService.createCollection(
  name: _nameController.text.trim(),
  type: widget.type,
  description: _descriptionController.text.trim().isEmpty ? null : _descriptionController.text.trim(),
  isPublic: _isPublic,
  coverImage: coverImageUrl,  // 传递封面URL
);
```

## 📝 使用说明

### 方式一：选择本地图片
1. 点击"点击选择封面图片"区域
2. 从相册选择图片
3. 预览图片
4. 如需更换，点击右上角关闭按钮后重新选择

### 方式二：输入图片URL
1. 在"或输入图片URL"输入框中输入图片链接
2. URL必须以 `http://` 或 `https://` 开头
3. 点击创建收藏夹

### 注意事项
- 封面图片是可选的，可以不设置
- 建议图片比例为 16:9
- 本地图片会被压缩（最大1920x1080，质量85%）
- URL方式直接使用输入的链接

## ⚠️ 当前限制

### 本地图片上传
目前**本地图片选择功能仅用于预览**，实际创建时使用URL输入框的值。

原因：需要后端提供图片上传接口。
