## 🔑 关键字段

### User模型字段

```dart
class User {
  final int id;              // 数据库ID
  final String userCode;     // 4位数字识别码 ⭐
  final String username;     // 用户名
  final String phone;        // 手机号
  final String? avatar;      // 头像URL
  final String createdAt;    // 创建时间
}
```

### 后端返回格式

```json
{
  "id": 1,
  "userCode": "1234",        // 或 "user_code"
  "username": "张三",
  "phone": "13912345678",
  "avatar": null,
  "createdAt": "2026-02-28T10:30:00"
}
```

## 🐛 常见问题

### Q1: 用户ID显示为空
**原因**: 后端未返回 `user_code` 字段  
**解决**: 确保后端API返回 `userCode` 或 `user_code`

### Q2: 点击设置没反应
**原因**: 未导入 `settings_page.dart`  
**解决**: 检查导入语句 `import 'settings_page.dart';`

### Q3: 退出登录后仍显示用户信息
**原因**: 本地数据未清除  
**解决**: 检查 `ApiService.logout()` 是否正常执行

### Q4: 显示"未登录"
**原因**: 本地没有用户信息  
**解决**: 重新登录应用

## 🔧 开发者注意事项

### 1. 后端API要求
- 登录接口必须返回 `user_code` 字段
- `user_code` 必须是4位数字字符串
- 建议格式：`"userCode": "1234"`

### 2. 本地存储
- Token存储在：`auth_token.json`
- 用户信息存储在：`user_info.json`
- 退出登录会清除这两个文件

### 3. 导航路由
- 设置页面：`SettingsPage()`
- 编辑资料：`EditProfilePage()`
- 关注列表：`FollowListPage()`

### 4. 状态管理
- 使用 `setState()` 更新UI
- 使用 `mounted` 检查组件是否存在
- 使用 `context.mounted` 检查上下文有效性
