> **修复日期**: 2026-03-04  
> **问题**: 前后端数据格式不匹配导致收藏夹无法加载

---

## 🐛 问题描述

### 错误信息
```
type 'List<dynamic>' is not a subtype of type 'Map<String, dynamic>' in type cast
```

### 根本原因
后端 API 直接返回数组格式：
```json
[]
```

前端期望的是标准 ApiResponse 格式：
```json
{
  "code": 200,
  "message": "success",
  "data": []
}
```

2. **`getFavoriteItems()`** - 获取收藏项列表

#### 修复逻辑：
```dart
// 兼容两种响应格式
final jsonResponse = jsonDecode(response.body);

if (jsonResponse is List) {
  // 后端直接返回数组
  final collections = jsonResponse
      .map((item) => Collection.fromJson(item as Map<String, dynamic>))
      .toList();
  return ApiResponse<List<Collection>>(
    code: 200,
    message: 'success',
    data: collections,
  );
} else if (jsonResponse is Map<String, dynamic>) {
  // 标准 ApiResponse 格式
  return ApiResponse<List<Collection>>.fromJson(
    jsonResponse,
    (data) {
      final list = data as List<dynamic>;
      return list.map((item) => Collection.fromJson(item as Map<String, dynamic>)).toList();
    },
  );
}
```

## 💡 经验总结

### 1. 前后端数据格式统一
- 建议后端统一使用标准 ApiResponse 格式
- 或者前端统一处理两种格式（当前方案）

### 2. 文件结构规范
- 严格遵守项目规则文档中的目录分级规范
- 二级页面必须放在对应一级文件夹的子文件夹中

### 3. 导入路径管理
- 移动文件后必须更新所有导入路径
- 使用相对路径时要注意层级关系

### 4. 错误排查流程
1. 查看错误日志定位问题
2. 检查前后端数据格式是否匹配
3. 验证文件路径和导入是否正确
4. 运行 `flutter analyze` 检查所有问题
