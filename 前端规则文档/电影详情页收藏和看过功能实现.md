# 电影详情页收藏和看过功能实现文档

## 概述

在电影详情页实现了收藏和标记看过功能，包括：
1. 收藏按钮：点击后弹出收藏夹选择对话框，支持添加到多个收藏夹
2. 标记看过按钮：点击后标记电影为看过，并显示成功提示对话框

## 实现内容

### 1. 收藏功能

#### 1.1 功能特性
- 点击"收藏"按钮弹出收藏夹选择对话框
- 显示用户所有的电影类型收藏夹
- 支持多选，可以同时添加到多个收藏夹
- 显示每个收藏夹的名称、描述和图标
- 实时显示已选择的收藏夹数量
- 添加成功后显示成功提示，包含成功和失败的数量

#### 1.2 收藏夹选择对话框
```dart
class _CollectionSelectionDialog extends StatefulWidget {
  final List<Collection> collections;
  final int movieId;
  final Future<void> Function(List<Collection>) onCollectionsSelected;
}
```

**对话框特性：**
- 使用 `CheckboxListTile` 实现多选
- 显示收藏夹图标、名称和描述
- 底部显示"添加 (N)"按钮，N为选中数量
- 提交时显示加载状态
- 自动关闭对话框

#### 1.3 API调用
```dart
// 获取电影类型的收藏夹
final response = await ApiService.getCollectionsByType('MOVIE');

// 添加到收藏夹（使用 tmdbId）
final response = await ApiService.addFavoriteItem(
  collectionId: collection.id,
  itemType: 'MOVIE',
  tmdbId: widget.movieId,  // 使用 TMDB ID
);
```

**重要说明：**
- 收藏电影时使用 `tmdbId` 字段，而不是 `itemId`
- 后端会自动从TMDB获取电影信息并保存到本地数据库
- 如果电影已存在于本地数据库，则直接使用

#### 1.4 错误处理
- 如果用户没有创建收藏夹，提示先创建收藏夹
- 如果加载收藏夹失败，显示错误提示
- 如果添加失败，显示失败数量

### 2. 标记看过功能

#### 2.1 功能特性
- 点击"标记看过"按钮标记电影为看过
- 标记成功后显示成功对话框
- 对话框包含绿色勾选图标和成功提示
- 提示用户可以在"已看片单"中查看
- 防止重复标记

#### 2.3 API调用
```dart
final response = await ApiService.markAsWatched(
  tmdbId: widget.movieId,  // 使用 TMDB ID

```

**重要说明：**
- 标记看过时使用 `tmdbId` 字段
- 后端会自动从TMDB获取电影信息并保存到本地数据库
- 可选参数：`rating`（评分）和 `note`（观影笔记）

#### 2.4 状态管理
```dart
bool _isWatched = false;  // 是否已看过
bool _isFavorited = false;  // 是否已收藏
```

- 标记成功后更新 `_isWatched` 状态
- 按钮图标根据状态变化（实心/空心）
- 防止重复标记

### 3. API服务修改

#### 3.1 修改 `addFavoriteItem` 方法
```dart
static Future<ApiResponse<FavoriteItem>> addFavoriteItem({
  required int collectionId,
  required String itemType,
  int? tmdbId,      // 电影使用 tmdbId
  int? itemId,      // 活动使用 itemId
  String? note,
})
```

**变更说明：**
- 将 `itemId` 改为可选参数
- 添加 `tmdbId` 可选参数
- 根据 `itemType` 自动选择使用哪个ID字段
- MOVIE类型使用 `tmdbId`
- EVENT类型使用 `itemId`

#### 3.2 修改 `markAsWatched` 方法
```dart
static Future<ApiResponse<WatchedMovie>> markAsWatched({
  required int tmdbId,  // 改为 tmdbId
  double? rating,
  String? note,
})
```

**变更说明：**
- 将参数从 `movieId` 改为 `tmdbId`
- 请求体中使用 `tmdbId` 字段

### 4. UI优化

#### 4.1 按钮状态
- 收藏按钮：根据 `_isFavorited` 显示实心/空心爱心图标
- 看过按钮：根据 `_isWatched` 显示实心/空心勾选图标

#### 4.2 提示信息
- 收藏成功：显示绿色SnackBar，包含成功数量
- 收藏失败：显示红色SnackBar
- 标记看过成功：显示美观的对话框
- 标记看过失败：显示SnackBar

#### 4.3 加载状态
- 收藏夹选择对话框提交时显示加载指示器
- 防止重复提交

## 注意事项

### 1. TMDB ID vs 本地电影ID
- **前端传递**：使用 TMDB ID（`tmdbId`）
- **后端返回**：返回本地数据库ID（`movieId` 或 `itemId`）
- **自动转换**：后端自动处理TMDB ID到本地ID的转换
- **自动保存**：如果电影不存在，后端自动从TMDB获取并保存

### 2. 收藏夹类型
- 只显示 `MOVIE` 类型的收藏夹
- 不显示 `EVENT` 类型的收藏夹
- 系统收藏夹和自定义收藏夹都会显示

### 3. 重复操作处理
- 标记看过：检查 `_isWatched` 状态，防止重复标记
- 收藏：后端会处理重复收藏的情况
- 如果已收藏，后端可能返回错误或成功（取决于后端实现）

### 4. 错误处理
- 网络错误：显示友好的错误提示
- 没有收藏夹：提示用户先创建收藏夹
- 部分失败：显示成功和失败的数量
