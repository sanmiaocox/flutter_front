## 🔌 后端接口对接

### 1. 注册接口

**后端接口**: `POST http://localhost:7070/api/auth/register`

**前端实现**: `ApiService.register()`

**请求参数**:
```dart
{
  "username": "用户名",  // 2-50个字符
  "phone": "手机号",     // 11位数字
  "password": "密码"     // 6-20个字符
}
```

**响应处理**:
- 成功 (code: 200): 显示成功提示，返回登录页
- 用户名已存在 (code: 1001): 显示错误提示
- 手机号已注册 (code: 1002): 显示错误提示
- 参数校验失败 (code: 400): 显示错误提示
- 网络错误 (code: -1): 显示网络错误提示

---

### 2. 登录接口

**后端接口**: `POST http://localhost:7070/api/auth/login`

**前端实现**: `ApiService.login()`

**请求参数**:
```dart
{
  "phone": "手机号",
  "password": "密码"
}
```

**响应处理**:
- 成功 (code: 200): 
  - 保存Token到本地
  - 保存用户信息到本地
  - 跳转到主页
- 手机号或密码错误 (code: 1003): 显示错误提示
- 参数校验失败 (code: 400): 显示错误提示
- 网络错误 (code: -1): 显示网络错误提示

### 常见问题排查

#### 问题1: 网络请求失败

**错误信息**: `网络请求失败: SocketException`

**原因**: 
- 后端服务未启动
- API地址配置错误
- 网络连接问题

**解决方案**:
1. 确认后端服务已启动
2. 检查 `api_config.dart` 中的地址配置
3. 如果使用模拟器，确保可以访问localhost

**Android模拟器特殊说明**:
- Android模拟器不能使用 `localhost`
- 需要使用 `10.0.2.2` 代替 `localhost`
- 修改配置: `http://10.0.2.2:7070`

**iOS模拟器特殊说明**:
- iOS模拟器可以直接使用 `localhost`
- 如果不行，使用电脑的局域网IP

---

#### 问题2: 参数校验失败

**错误信息**: `参数校验失败`

**原因**: 输入的数据不符合要求

**解决方案**:
- 用户名: 2-50个字符
- 手机号: 必须是11位数字，以1开头
- 密码: 6-20个字符

---

#### 问题3: 用户名或手机号已存在

**错误信息**: `用户名已存在` 或 `手机号已被注册`

**原因**: 数据库中已有相同的用户名或手机号

**解决方案**:
- 更换用户名或手机号
- 或在数据库中删除测试数据

---

#### 问题4: Token未保存

**原因**: 本地存储失败

**解决方案**:
1. 检查应用是否有文件读写权限
2. 查看控制台日志
3. 尝试重新安装应用

## 📝 代码示例

### 调用注册接口

```dart
final response = await ApiService.register(
  username: '测试用户',
  phone: '13800138000',
  password: '123456',
);

if (response.isSuccess) {
  print('注册成功: ${response.data!.username}');
} else {
  print('注册失败: ${response.message}');
}
```

### 调用登录接口

```dart
final response = await ApiService.login(
  phone: '13800138000',
  password: '123456',
);

if (response.isSuccess) {
  print('登录成功');
  print('Token: ${response.data!.token}');
  print('用户: ${response.data!.user.username}');
} else {
  print('登录失败: ${response.message}');
}
```

### 检查登录状态

```dart
final isLoggedIn = await StorageService.isLoggedIn();
if (isLoggedIn) {
  print('用户已登录');
  final user = await StorageService.getUser();
  print('当前用户: ${user?.username}');
} else {
  print('用户未登录');
}
```

### 退出登录

```dart
await ApiService.logout();
print('已退出登录');
```
