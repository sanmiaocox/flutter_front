## ⚠️ 注意事项

### 1. 后端API需要返回user_code

确保后端登录接口返回的用户信息包含 `user_code` 字段：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "...",
    "user": {
      "id": 1,
      "userCode": "1234",  // 或 "user_code": "1234"
      "username": "张三",
      "phone": "13912345678",
      "avatar": null,
      "createdAt": "2026-02-28T..."
    }
  }
}
```

### 2. user_code格式

- 必须是4位数字
- 例如：`1234`, `0001`, `9999`
- 在数据库中是唯一的

### 3. 设置页面功能

- 当前大部分设置项是占位功能
- 点击会显示"功能开发中..."提示
- 只有退出登录功能完全实现
