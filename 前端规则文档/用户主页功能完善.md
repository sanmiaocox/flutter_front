## 技术实现

### 1. Tab 控制器

```dart
class _UserProfilePageState extends State<UserProfilePage> 
    with TickerProviderStateMixin, RouteAware, AutoRefreshMixin {
  
  late TabController _tabController;
  
  @override
  void initState() {
    super.initState();
    _tabController = TabController(length: 2, vsync: this);
    _tabController.addListener(_onTabChanged);
    _loadUserProfile();
    _loadFeeds();
  }
  
  void _onTabChanged() {
    // 切换到活动 Tab 时才加载活动数据（懒加载）
    if (_tabController.index == 1 && _events.isEmpty && !_isLoadingEvents) {
      _loadEvents();
    }
  }
}
```

### 2. 动态列表实现

```dart
// 动态数据
final List<Feed> _feeds = [];
bool _isLoadingFeeds = false;
bool _hasMoreFeeds = true;
int _currentFeedPage = 0;
final ScrollController _feedScrollController = ScrollController();

// 加载动态
Future<void> _loadFeeds() async {
  final response = await ApiService.getUserFeeds(
    userId: widget.userId,
    page: 0,
    size: 20,
  );
  
  if (response.code == 200 && response.data != null) {
    setState(() {
      _feeds.clear();
      _feeds.addAll(response.data!.content);
      _currentFeedPage = 0;
      _hasMoreFeeds = response.data!.number < response.data!.totalPages - 1;
    });
  }
}

// 滚动监听
void _onFeedScroll() {
  if (_feedScrollController.position.pixels >= 
      _feedScrollController.position.maxScrollExtent - 200) {
    if (!_isLoadingFeeds && _hasMoreFeeds) {
      _loadMoreFeeds();
    }
  }
}
```

### 3. 活动列表实现

```dart
// 活动数据
final List<Event> _events = [];
bool _isLoadingEvents = false;
bool _hasMoreEvents = true;
int _currentEventPage = 0;
final ScrollController _eventScrollController = ScrollController();

// 加载活动
Future<void> _loadEvents() async {
  final response = await ApiService.getUserEvents(
    userId: widget.userId,
    page: 0,
    size: 20,
  );
  
  if (response.isSuccess && response.data != null) {
    final data = response.data!;
    final content = data['content'] as List<dynamic>;
    final totalPages = data['totalPages'] as int? ?? 1;
    
    setState(() {
      _events.clear();
      _events.addAll(
        content.map((item) => Event.fromJson(item)).toList()
      );
      _currentEventPage = 0;
      _hasMoreEvents = _currentEventPage + 1 < totalPages;
    });
  }
}
```

### 4. API 服务新增方法

```dart
/// 获取用户活动列表
/// 
/// [userId] 用户ID
/// [page] 页码（默认0）
/// [size] 每页数量（默认20）
static Future<ApiResponse<Map<String, dynamic>>> getUserEvents({
  required int userId,
  int page = 0,
  int size = 20,
}) async {
  try {
    final url = Uri.parse('$baseUrl/api/users/$userId/events?page=$page&size=$size');
    final headers = await getAuthHeaders();
    
    final response = await http.get(url, headers: headers);
    final jsonResponse = jsonDecode(response.body) as Map<String, dynamic>;
    
    return ApiResponse<Map<String, dynamic>>.fromJson(
      jsonResponse,
      (data) => data as Map<String, dynamic>,
    );
  } catch (e) {
    return ApiResponse<Map<String, dynamic>>(
      code: -1,
      message: '网络请求失败: $e',
      data: null,
    );
  }
}
```

## 性能优化

### 1. 懒加载

- 首次进入页面只加载用户信息和动态列表
- 切换到活动 Tab 时才加载活动数据
- 避免不必要的 API 请求

### 2. 分页加载

- 每次加载 20 条数据
- 滚动到底部前 200px 时自动加载下一页
- 避免一次性加载大量数据

### 3. 下拉刷新

- 支持下拉刷新重新加载数据
- 刷新时清空现有数据，从第一页开始加载

### 4. 滚动性能

- 使用独立的 `ScrollController` 管理滚动
- 监听滚动位置实现自动加载更多
- 避免重复加载
