#### 1. 添加图片上传API方法
```dart
// lib/services/api_service.dart

/// 上传图片
static Future<ApiResponse<String>> uploadImage(File imageFile) async {
  try {
    final url = Uri.parse('$baseUrl/api/upload/image');
    
    var request = http.MultipartRequest('POST', url);
    
    // 添加认证头
    final token = await StorageService.getToken();
    if (token != null) {
      request.headers['Authorization'] = 'Bearer $token';
    }
    
    // 添加文件
    request.files.add(
      await http.MultipartFile.fromPath('file', imageFile.path),
    );

    final streamedResponse = await request.send();
    final response = await http.Response.fromStream(streamedResponse);

    if (response.statusCode == 200) {
      final jsonResponse = jsonDecode(response.body);
      
      // 支持两种响应格式
      if (jsonResponse.containsKey('url')) {
        return ApiResponse<String>(
          code: 200,
          message: 'success',
          data: jsonResponse['url'] as String,
        );
      } else if (jsonResponse.containsKey('data')) {
        return ApiResponse<String>.fromJson(
          jsonResponse,
          (data) => data as String,
        );
      }
    }
    
    return ApiResponse<String>(
      code: response.statusCode,
      message: '上传失败',
      data: null,
    );
  } catch (e) {
    return ApiResponse<String>(
      code: -1,
      message: '上传失败: $e',
      data: null,
    );
  }
}
```

## 🔧 后端需要实现的接口

### 接口规范

#### 端点
```
POST /api/upload/image
```

#### 请求
- **Content-Type**: `multipart/form-data`
- **Authorization**: `Bearer {token}`
- **Body**: 
  - `file`: 图片文件（字段名必须是 `file`）

#### 响应格式（推荐）

**方式一：直接返回URL**
```json
{
  "url": "https://example.com/uploads/images/abc123.jpg"
}
```

**方式二：标准ApiResponse格式**
```json
{
  "code": 200,
  "message": "上传成功",
  "data": "https://example.com/uploads/images/abc123.jpg"
}
```

#### 错误响应
```json
{
  "code": 400,
  "message": "文件类型不支持",
  "data": null
}
```

## 💻 后端实现示例（Java Spring Boot）

### 1. 创建上传控制器

```java
@RestController
@RequestMapping("/api/upload")
public class UploadController {

    @Value("${upload.path}")
    private String uploadPath;

    @Value("${upload.url-prefix}")
    private String urlPrefix;

    @PostMapping("/image")
    public ResponseEntity<?> uploadImage(
            @RequestParam("file") MultipartFile file,
            @AuthenticationPrincipal UserDetails userDetails) {
        
        try {
            // 1. 验证文件
            if (file.isEmpty()) {
                return ResponseEntity.badRequest()
                    .body(Map.of("code", 400, "message", "文件不能为空"));
            }

            // 2. 验证文件类型
            String contentType = file.getContentType();
            if (!isImageFile(contentType)) {
                return ResponseEntity.badRequest()
                    .body(Map.of("code", 400, "message", "只支持图片文件"));
            }

            // 3. 验证文件大小（例如：最大5MB）
            if (file.getSize() > 5 * 1024 * 1024) {
                return ResponseEntity.badRequest()
                    .body(Map.of("code", 400, "message", "文件大小不能超过5MB"));
            }

            // 4. 生成唯一文件名
            String originalFilename = file.getOriginalFilename();
            String extension = getFileExtension(originalFilename);
            String filename = UUID.randomUUID().toString() + extension;

            // 5. 创建上传目录（按日期分类）
            String dateFolder = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy/MM/dd"));
            Path uploadDir = Paths.get(uploadPath, "images", dateFolder);
            Files.createDirectories(uploadDir);

            // 6. 保存文件
            Path filePath = uploadDir.resolve(filename);
            file.transferTo(filePath.toFile());

            // 7. 生成访问URL
            String imageUrl = urlPrefix + "/images/" + dateFolder + "/" + filename;

            // 8. 返回URL
            return ResponseEntity.ok(Map.of("url", imageUrl));

        } catch (IOException e) {
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
                .body(Map.of("code", 500, "message", "上传失败: " + e.getMessage()));
        }
    }

    private boolean isImageFile(String contentType) {
        return contentType != null && (
            contentType.equals("image/jpeg") ||
            contentType.equals("image/png") ||
            contentType.equals("image/gif") ||
            contentType.equals("image/webp")
        );
    }

    private String getFileExtension(String filename) {
        if (filename == null) return ".jpg";
        int lastDot = filename.lastIndexOf('.');
        return lastDot > 0 ? filename.substring(lastDot) : ".jpg";
    }
}
```

### 2. 配置文件（application.yml）

```yaml
upload:
  # 本地存储路径
  path: /var/www/uploads
  # 访问URL前缀
  url-prefix: http://localhost:7070/uploads

spring:
  servlet:
    multipart:
      # 最大文件大小
      max-file-size: 5MB
      # 最大请求大小
      max-request-size: 10MB
```

### 3. 配置静态资源访问

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Value("${upload.path}")
    private String uploadPath;

    @Override
    public void addResourceHandlers(ResourceHandlerRegistry registry) {
        // 配置上传文件的访问路径
        registry.addResourceHandler("/uploads/**")
                .addResourceLocations("file:" + uploadPath + "/");
    }
}
```

## 🎯 完整流程

### 用户操作流程
1. 用户打开创建收藏夹页面
2. 点击"选择封面图片"
3. 从相册选择图片
4. 预览图片
5. 填写收藏夹名称等信息
6. 点击"创建收藏夹"

### 系统处理流程
1. **前端**：检测到有本地图片
2. **前端**：显示"正在上传封面图片..."提示
3. **前端**：调用 `ApiService.uploadImage()` 上传图片
4. **后端**：接收图片文件
5. **后端**：验证文件类型和大小
6. **后端**：生成唯一文件名
7. **后端**：保存文件到服务器
8. **后端**：返回图片URL
9. **前端**：获取图片URL
10. **前端**：调用 `ApiService.createCollection()` 创建收藏夹，传递图片URL
11. **后端**：保存收藏夹信息（包含 `cover_image` 字段）
12. **前端**：显示"收藏夹创建成功"
