# 收藏夹功能实现说明

> **实现日期**: 2026-03-04  
> **版本**: v1.0

---

## 📋 功能概述

收藏夹功能是个人中心的二级页面，允许用户创建和管理多个收藏夹，分别收藏电影和活动。

### 核心功能

1. **收藏夹列表页**
   - 展示用户的所有收藏夹
   - 支持按类型筛选（电影收藏夹/活动收藏夹）
   - 显示收藏夹封面、名称、描述、项目数量、公开性
   - 区分系统收藏夹和用户创建的收藏夹

2. **创建收藏夹**
   - 支持创建电影收藏夹（MOVIE）和活动收藏夹（EVENT）
   - 可设置收藏夹名称、描述
   - 可选择公开或私密
   - 电影收藏夹只能收藏电影，活动收藏夹只能收藏活动

3. **收藏夹详情页**
   - 展示收藏夹中的所有收藏项
   - 支持移除收藏项
   - 支持编辑收藏夹信息
   - 支持删除收藏夹（系统收藏夹不可删除）

## 🎨 界面设计

### 1. 收藏夹列表页 (FavoritesPage)

**布局结构**：
- 顶部：AppBar + TabBar（电影收藏夹 / 活动收藏夹）
- 内容区：收藏夹卡片列表 + 创建按钮

**收藏夹卡片**：
- 左侧：封面图或图标（80x80，圆角12）
- 中间：收藏夹名称、描述、项目数量、公开性标识
- 右侧：箭头图标
- 系统收藏夹显示"系统"标签

**空状态**：
- 显示图标和提示文字
- 显示创建按钮

**交互**：
- 点击收藏夹卡片：进入收藏夹详情页
- 点击创建按钮：进入创建收藏夹页
- 下拉刷新：重新加载收藏夹列表

### 2. 创建收藏夹页 (CreateCollectionPage)

**表单字段**：
- 收藏夹名称（必填，最多50字符）
- 收藏夹描述（可选，最多200字符）
- 隐私设置（公开/私密）

**类型提示卡片**：
- 显示收藏夹类型图标和说明
- 电影收藏夹：红色主题，只能收藏电影
- 活动收藏夹：紫色主题，只能收藏活动

**提交流程**：
1. 验证表单
2. 调用 API 创建收藏夹
3. 显示加载状态
4. 成功后返回列表页并刷新

### 3. 收藏夹详情页 (CollectionDetailPage)

**布局结构**：
- 顶部：可展开的 SliverAppBar（显示封面或渐变背景）
- 收藏夹信息卡片：类型、公开性、描述、项目数量
- 收藏项列表：卡片式展示

**收藏项卡片**：
- 左侧：封面图（60x90）
- 中间：标题、年份、评分、备注
- 右侧：删除按钮

**菜单功能**：
- 编辑收藏夹（TODO）
- 删除收藏夹（系统收藏夹不可删除）

**空状态**：
- 显示提示文字，引导用户去发现页面收藏内容

## 🔌 API 集成

### 使用的 API 接口

1. **获取收藏夹列表**
   ```dart
   ApiService.getCollections()
   ```

2. **创建收藏夹**
   ```dart
   ApiService.createCollection(
     name: '收藏夹名称',
     type: 'MOVIE', // 或 'EVENT'
     description: '描述',
     isPublic: true,
   )
   ```

3. **获取收藏夹详情**
   ```dart
   ApiService.getCollectionDetail(collectionId)
   ```

4. **获取收藏项列表**
   ```dart
   ApiService.getFavoriteItems(collectionId)
   ```

5. **移除收藏项**
   ```dart
   ApiService.removeFavoriteItem(
     collectionId: collectionId,
     itemType: 'MOVIE', // 或 'EVENT'
     itemId: itemId,
   )
   ```

6. **删除收藏夹**
   ```dart
   ApiService.deleteCollection(collectionId)
   ```

## 🔄 业务逻辑

### 用户注册时
- 后端自动创建"默认电影收藏夹"（MOVIE 类型，系统收藏夹）
- 后端自动创建"默认活动收藏夹"（EVENT 类型，系统收藏夹）

### 创建收藏夹
1. 用户选择类型（电影/活动）
2. 填写名称和描述
3. 选择公开性
4. 提交到后端
5. 后端验证并创建
6. 返回列表页并刷新

### 收藏内容
1. 在电影详情页或活动详情页点击"收藏"
2. 选择目标收藏夹（类型必须匹配）
3. 可选添加备注
4. 提交到后端
5. 收藏夹项目数量 +1

### 移除收藏
1. 在收藏夹详情页点击删除按钮
2. 显示确认对话框
3. 确认后调用 API
4. 收藏夹项目数量 -1
5. 刷新列表

### 删除收藏夹
1. 在收藏夹详情页点击菜单中的"删除"
2. 系统收藏夹不显示删除选项
3. 显示确认对话框（提示会删除所有收藏项）
4. 确认后调用 API
5. 返回列表页并刷新

## ⚠️ 注意事项

1. **类型限制**
   - 电影收藏夹只能收藏电影
   - 活动收藏夹只能收藏活动
   - 后端会验证类型匹配

2. **系统收藏夹**
   - 不能删除
   - 不能修改名称和类型
   - 可以修改描述、公开性、封面

3. **权限控制**
   - 只能操作自己的收藏夹
   - 可以查看他人的公开收藏夹（TODO）

4. **数据同步**
   - 操作后需要刷新数据
   - 使用 `Navigator.pop(true)` 传递刷新标识

## 📝 代码示例

### 从个人中心进入收藏夹
```dart
// profile_page.dart
void _onFavoritesTap() {
  Navigator.of(context).push(
    MaterialPageRoute(
      builder: (_) => const FavoritesPage(),
    ),
  );
}
```

### 创建收藏夹
```dart
// create_collection_page.dart
final response = await ApiService.createCollection(
  name: _nameController.text.trim(),
  type: widget.type, // 'MOVIE' 或 'EVENT'
  description: _descriptionController.text.trim(),
  isPublic: _isPublic,
);

if (response.isSuccess) {
  Navigator.of(context).pop(true); // 返回并刷新
}
```

### 移除收藏项
```dart
// collection_detail_page.dart
final response = await ApiService.removeFavoriteItem(
  collectionId: widget.collection.id,
  itemType: item.itemType,
  itemId: item.itemId,
);

if (response.isSuccess) {
  _refreshData(); // 刷新列表
}
```
