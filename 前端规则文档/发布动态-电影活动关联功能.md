# 发布动态 - 电影和活动关联功能实现

## 功能概述

为发布动态页面添加了完整的电影和活动关联功能，用户可以在发布动态时选择关联的电影或活动。

## 实现的功能

### 1. 电影选择对话框 (MovieSelectionDialog)

#### 功能特性
- ✅ 默认显示热门电影列表
- ✅ 支持搜索电影（实时搜索）
- ✅ 显示电影海报、标题、年份、评分
- ✅ 点击电影自动保存到数据库并返回
- ✅ 搜索框支持清除按钮
- ✅ 加载状态显示

```dart
Future<void> _loadPopularMovies() async {
  final response = await ApiService.getPopularMovies(page: 1);
  if (response.code == 200 && response.data != null) {
    setState(() {
      _movies.clear();
      _movies.addAll(response.data!.results);

  }

```

**搜索电影**
```dart
Future<void> _searchMovies(String keyword) async {
  if (keyword.trim().isEmpty) {
    _loadPopularMovies();
    return;
  }
  
  final response = await ApiService.searchMovies(keyword: keyword, page: 1);
  if (response.code == 200 && response.data != null) {
    setState(() {
      _movies.clear();
      _movies.addAll(response.data!.results);
    });
  }
}
```

**选择电影**
```dart
Future<void> _selectMovie(TmdbMovie movie) async {
  // 先保存电影到数据库
  final response = await ApiService.saveMovieToDatabase(movie.id);
  if (response.code == 200 && response.data != null) {
    final movieId = response.data!['id'] as int;
    Navigator.pop(context, {
      'movieId': movieId,
      'movie': movie,
    });
  }
}
```

## 用户流程

### 电影关联流程

1. 用户点击"电影"按钮
2. 弹出电影选择对话框
3. 默认显示热门电影列表
4. 用户可以：
   - 浏览热门电影列表
   - 在搜索框输入关键词搜索
   - 点击清除按钮返回热门列表
5. 点击某个电影
6. 系统自动保存电影到数据库
7. 对话框关闭，主页面显示已关联的电影卡片

### 活动关联流程

1. 用户点击"活动"按钮
2. 弹出活动选择对话框
3. 默认显示"我创建的"活动列表
4. 用户可以：
   - 切换到"我参加的"标签
   - 浏览活动列表
5. 点击某个活动
6. 对话框关闭，主页面显示已关联的活动卡片

## UI 细节

### 电影项样式
- 海报：50×75px，圆角 4px
- 标题：15px，加粗，最多 2 行
- 年份：13px，灰色
- 评分：星星图标 + 数字
- 右侧箭头指示可点击

### 活动项样式
- 封面：60×60px，圆角 4px
- 标题：15px，加粗，最多 2 行
- 地点：图标 + 文字，13px，灰色
- 时间：图标 + 日期，13px，灰色
- 右侧箭头指示可点击

### 对话框样式
- 宽度：屏幕宽度的 90%
- 高度：屏幕高度的 80%
- 圆角：默认 Dialog 圆角
- 内边距：16px
- 标题：18px，加粗，蓝色
- 关闭按钮：右上角

## 错误处理

### 电影选择
- ✅ 搜索失败：保持当前列表
- ✅ 加载失败：显示空状态
- ✅ 保存失败：显示错误提示
- ✅ 图片加载失败：显示占位图标

### 活动选择
- ✅ 加载失败：显示空状态
- ✅ 无活动：显示"暂无活动"提示
- ✅ 图片加载失败：显示占位图标

## 性能优化

### 电影对话框
- 使用 `ListView.builder` 懒加载
- 搜索防抖（用户提交时才搜索）
- 图片使用 TMDB 的 w92 小尺寸

### 活动对话框
- 使用 `ListView.builder` 懒加载
- Tab 切换时不重新加载数据
- 使用 `SingleTickerProviderStateMixin` 优化动画
